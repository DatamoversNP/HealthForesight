# Cohort Builder Guide for Analysts

## What is a Cohort?

A **cohort** is a saved filter specification that groups policies (or other entities) based on shared characteristics. Think of it as a reusable "smart filter" that you can apply across multiple analyses.

## Why Cohorts are Useful for Analysts

### 1. **Reusable Policy Groups**
Instead of manually filtering policies every time you run an analysis, save commonly used groups as cohorts:
- "High Impact Policies" - Policies with >10% utilization change
- "Cost Reduction Policies" - Policies saving >$10k
- "New Policies" - Policies created in the last 30 days
- "Active Monitoring" - Policies currently being monitored

### 2. **Batch Analysis**
Run analyses on entire cohorts at once:
- Compare performance across all "High Impact Policies"
- Run sensitivity analysis on "Cost Reduction Policies"
- Generate reports for "New Policies" cohort

### 3. **Consistent Comparisons**
Use the same cohort definition across different analyses to ensure consistent comparisons:
- Track cohort metrics over time
- Compare cohort performance across different time periods
- Maintain consistent policy groupings for reporting

### 4. **Time-Saving**
Save time by reusing pre-defined cohorts instead of recreating filters:
- Quick access to frequently used policy groups
- Share cohorts with team members
- Build on existing cohorts for new analyses

## How to Use the Cohort Builder

### Step 1: Select a Cohort Shortcut
In the Analyst Dashboard, go to the "Cohort Builder" tab. You'll see pre-configured cohort shortcuts:
- **High Impact Policies**: Policies with >10% utilization change
- **Cost Reduction Policies**: Policies with >$10k cost savings
- **New Policies**: Policies created in last 30 days
- **Active Monitoring**: Policies in monitoring phase

### Step 2: Click "Build Cohort"
Clicking "Build Cohort" opens the Cohort Builder dialog, which shows:
- **Filter Criteria**: The filters that will be applied
- **Matching Policies**: Preview of policies that match the criteria
- **Policy Count**: How many policies are in the cohort

### Step 3: Customize the Cohort
- **Name**: Give your cohort a descriptive name (e.g., "High Impact Policies Q1 2024")
- **Description**: Add notes about what this cohort represents and how you'll use it
- **Review Matching Policies**: Verify the policies match your expectations

### Step 4: Save the Cohort
Click "Save Cohort" to store it for future use. Saved cohorts can be:
- Used in analyses
- Shared with team members
- Updated or deleted later

## Use Cases

### Use Case 1: Quarterly Performance Review
1. Create a cohort of "High Impact Policies" for Q1
2. Run batch analysis on the cohort
3. Compare Q1 cohort performance to Q2 cohort
4. Generate executive report for the cohort

### Use Case 2: Sensitivity Analysis
1. Create a cohort of policies with high uncertainty
2. Run sensitivity analysis on the entire cohort
3. Identify which policies need more data
4. Prioritize data collection efforts

### Use Case 3: Policy Comparison
1. Create cohorts for different policy types
2. Compare performance metrics across cohorts
3. Identify best-performing policy categories
4. Recommend policy design improvements

### Use Case 4: Trend Analysis
1. Create a cohort of "New Policies"
2. Track cohort metrics over time
3. Compare new policy performance to established policies
4. Identify patterns in policy effectiveness

## Benefits

✅ **Efficiency**: Save time by reusing pre-defined groups  
✅ **Consistency**: Use the same definitions across analyses  
✅ **Collaboration**: Share cohorts with team members  
✅ **Scalability**: Run analyses on large policy groups easily  
✅ **Traceability**: Track which policies were included in each analysis  

## Next Steps

After creating a cohort, you can:
1. Use it in impact analyses
2. Run sensitivity analysis on the cohort
3. Generate cohort-specific reports
4. Export cohort data for external analysis
5. Compare cohorts side-by-side

---

**Note**: Cohorts are saved filter specifications, not static snapshots. If policies change, the cohort will reflect those changes when used in analyses.
