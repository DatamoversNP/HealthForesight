# Simple Commands to Start Web Server

## Just Copy and Paste These 2 Commands:

### Command 1: Go to web directory
```bash
cd "/Users/nilesh.patil/Downloads/Utilization Elastisity and Policy Impact Solution/apps/web"
```

### Command 2: Start the server
```bash
npm run dev
```

## That's It!

After running these two commands, wait 10-15 seconds, then open:
**http://localhost:3050**

## What You'll See:

```
  VITE v5.x.x  ready in xxx ms
  ➜  Local:   http://localhost:3050/
```

When you see this, the server is ready!

## To Stop the Server:
Press `Ctrl + C` in the Terminal
