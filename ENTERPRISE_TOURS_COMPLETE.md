## 🚀 How to Use

### For End Users
1. **First-time tour** automatically starts on dashboard
2. **Click tour button** (?) on any page for module-specific tour
3. **Navigate through steps** using Next/Back buttons
4. **Skip anytime** if needed
5. **Progress is saved** automatically

### For Demos
1. **Reset tour state** before demo:
   ```javascript
   localStorage.removeItem('uepi_first_time_tour')
   localStorage.removeItem('uepi_tour_state')
   ```
2. **Start with dashboard tour** for overview
3. **Navigate to specific modules** and show their tours
4. **Highlight key features** using tour explanations
5. **Show value propositions** and enterprise capabilities

## 🔧 Customization

### Adding Screenshots
To add screenshots to tour steps, update the tour content:

```typescript
{
  target: '.my-feature',
  content: (
    <div>
      <h3>Feature Title</h3>
      <p>Description...</p>
      <img 
        src="/screenshots/feature.png" 
        alt="Feature Screenshot"
        style={{ 
          width: '100%', 
          maxWidth: '500px', 
          marginTop: '12px',
          borderRadius: '8px',
          border: '1px solid #ddd',
          boxShadow: '0 2px 8px rgba(0,0,0,0.1)'
        }}
      />
    </div>
  ),
}
```

### Styling Customization
