2. **Copies entire data/ directory** from project root
3. **Verifies data is included** (shows summary)
4. **Creates ZIP** with all data (~600MB+)
5. **Deploys to Azure**
6. **Sets STORAGE_PATH** to `/home/site/wwwroot/data`
7. **Restarts services**
