## Screenshot Guidelines

### Image Specifications
- **Format:** PNG (preferred) or JPG
- **Resolution:** Minimum 1920x1080 for desktop, include mobile versions if needed
- **File Size:** Optimize to < 500KB per image
- **Naming:** Use kebab-case (lowercase with hyphens)

### Content Guidelines
- **Show real data** when possible (use realistic examples)
- **Highlight key features** with annotations if helpful
- **Include context** - show enough of the UI for orientation
- **Consistent styling** - use same browser/theme across screenshots
- **Privacy:** Ensure no real patient or sensitive data

### Taking Screenshots
1. Use browser DevTools to capture at consistent viewport sizes
2. Hide personal/sensitive information
3. Use consistent browser theme (light/dark)
4. Capture at full resolution
5. Crop to focus on relevant areas
