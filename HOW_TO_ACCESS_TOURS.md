# 🎯 How to Access Product Tours

## Quick Access Guide

Product tours are accessible through **Tour Buttons** (❓ help icon) located on key pages throughout the application.

## 📍 Where to Find Tour Buttons

### 1. **Dashboard** (`/` or `/dashboard`)
   - **Location**: Top-right corner of the dashboard header
   - **Icon**: ❓ Help icon with optional red badge (if tour not completed)
   - **Tour**: Dashboard Overview Tour
   - **What it covers**: 
     - Dashboard navigation and persona views
     - Key metrics cards
     - Decision recommendations
     - Cost trend forecasts
     - Risk register
     - Policy performance charts

### 2. **Policy Catalog** (`/policies`)
   - **Location**: Top-right corner of the page header
   - **Icon**: ❓ Help icon
   - **Tour**: Policy Catalog Tour
   - **What it covers**:
     - Policy catalog overview
     - Search and filter functionality
     - Policy list and cards
     - Creating new policies

### 3. **Policy Builder** (`/policies/builder`)
   - **Location**: Top-right corner of the page header
   - **Icon**: ❓ Help icon (small size)
   - **Tour**: Policy Builder Tour
   - **What it covers**:
     - Policy builder introduction
     - Step-by-step wizard navigation
     - Scope configuration
     - Levers configuration
     - Conditions and exceptions

### 4. **Policy Workspace** (`/policies/workspace/:id`)
   - **Location**: Top-right corner, next to other action buttons
   - **Icon**: ❓ Help icon (small size)
   - **Tour**: Policy Workspace Tour
   - **What it covers**:
     - Workspace tabs overview
     - Assumptions manager
     - Guardrails manager
     - Version control
     - Decisions, Evidence, Forecasts, Scenarios, etc.

### 5. **Analysis Workspace** (`/analyses`)
   - **Location**: Top-right corner of the page header
   - **Icon**: ❓ Help icon (small size)
   - **Tour**: Analysis Workspace Tour
   - **What it covers**:
     - Analysis workspace overview
     - Analysis tabs navigation
     - Impact results display
     - Trust panel interface

### 6. **What-If Analysis** (`/whatif`)
   - **Location**: Top-right corner of the page header
   - **Icon**: ❓ Help icon
   - **Tour**: What-If Analysis Tour
   - **What it covers**:
     - What-if analysis overview
     - Scenario builder interface
     - Scenario comparison view

### 7. **Data Ingestion** (`/ingestions`)
   - **Location**: Top-right corner of the page header
   - **Icon**: ❓ Help icon
   - **Tour**: Data Ingestion Tour
   - **What it covers**:
     - Ingestion dashboard overview
     - Upload interface
     - Ingestion history and monitoring

## 🚀 How to Start a Tour

### Method 1: Click the Tour Button
1. Navigate to any page listed above
2. Look for the **❓ help icon** in the top-right corner
3. Click the icon to start the tour for that page

### Method 2: First-Time Tour (Automatic)
- On your **first visit** to the dashboard, a tour will automatically start
- This is a one-time welcome tour
- You can skip it or complete it

### Method 3: Tour Badge Indicator
- If a tour hasn't been completed, the help icon will show a **red badge** (dot)
- This indicates there's a new tour available for that page
- Click the icon to start the tour

## 🎨 Tour Features

### Interactive Elements
- **Next Button**: Move to the next step
- **Back Button**: Go back to previous step
- **Skip Button**: Exit the tour
- **Progress Indicator**: Shows your progress through the tour

### Visual Highlights
- **Spotlight**: Highlights the element being explained
- **Tooltips**: Detailed explanations with screenshots
- **Smooth Animations**: Professional transitions between steps

### Tour Content
Each tour includes:
- **Detailed explanations** of features
- **Business value** and use cases
- **Tips and best practices**
- **Compliance notes** where relevant
- **Screenshots** (when available)

## 📝 Tour Completion

### Completion Status
- Tours are marked as "completed" when you finish them
- Completed tours won't show the red badge
- You can restart any tour by clicking the help icon again

### Feedback
- After completing a tour, you'll be prompted for feedback
- Provide ratings, helpfulness, and comments
- Feedback helps improve future tours

## 🔄 Restarting Tours

To restart a tour:
1. Navigate to the page
2. Click the **❓ help icon**
3. The tour will start from the beginning

## 💡 Tips

1. **Complete tours in order**: Start with Dashboard, then move to other pages
2. **Take your time**: Read through each step carefully
3. **Use screenshots**: Screenshots help visualize features
4. **Provide feedback**: Your feedback helps improve tours
5. **Skip if needed**: You can always skip and come back later

## 🐛 Troubleshooting

### Tour Button Not Visible?
- Make sure you're logged in
- Check that you're on the correct page
- Refresh the page if needed

### Tour Not Starting?
- Check browser console for errors
- Ensure JavaScript is enabled
- Try refreshing the page

### Screenshots Not Showing?
- Screenshots are optional and may not be available yet
- The tour will still work without screenshots
- Run `npm run capture-screenshots` to generate screenshots
